# java-wordle4j
Сделаны отдельные классы исключений в отдельном пакете. Написаны unit-тесты для основных классов (WordleDictionary и WordleGame), включая проверки корректной работы логики и тесты на выброс исключений. Дополнительно реализованы два теста на обработку ошибок. Тесты для main не реализованы(не знаю что там нужно проверять).
